# Assignment 2 — FUTURE ME

Computer Graphics / Modern OpenGL project.

## Theme

**FUTURE ME — AI / Computer Science Workstation**

The scene represents a future version of the student as a computer scientist:
- human future-self avatar in a futuristic suit with an augmented-reality visor
- futuristic workstation
- camera-facing digital monitor
- floating AI core
- Phong lighting
- 3D transformations
- 800 × 600 OpenGL window

## Project structure

This project intentionally follows the same overall structure as the
`momotheoxy/OpenGLStarter` reference:

```text
Assignment2_FutureMe/
├── .vscode/
│   ├── extensions.json
│   ├── launch.json
│   └── settings.json
├── Shaders/
│   ├── shader.frag
│   └── shader.vert
├── Models/
├── Textures/
├── src/
│   ├── Libs/
│   │   ├── Mesh.cpp
│   │   ├── Mesh.h
│   │   ├── Shader.cpp
│   │   ├── Shader.h
│   │   ├── Window.cpp
│   │   └── Window.h
│   ├── ProjectPaths.h.in
│   └── main.cpp
├── CMakeLists.txt
├── CMakePresets.json
├── vcpkg.json
└── README.md
```

`ProjectPaths.h` is generated by CMake, so shader paths are absolute and
do not depend on the program's current working directory.

## Requirements

- C++17
- CMake
- Ninja
- VS Code + CMake Tools (recommended)
- vcpkg
- OpenGL 3.3+
- macOS with Apple Silicon or Intel

## macOS setup

Install tools:

```bash
xcode-select --install
brew install git cmake ninja pkg-config
```

Install vcpkg in the recommended location:

```bash
git clone https://github.com/microsoft/vcpkg ~/vcpkg
~/vcpkg/bootstrap-vcpkg.sh
```

Check:

```bash
ls ~/vcpkg/scripts/buildsystems/vcpkg.cmake
```

## Configure

Apple Silicon:

```bash
cmake --preset "macOS Apple Silicon (arm64)"
```

Intel:

```bash
cmake --preset "macOS Intel (x64)"
```

## Build

Apple Silicon:

```bash
cmake --build build/mac-arm64
```

Intel:

```bash
cmake --build build/mac-intel
```

## Run

The executable will be inside the selected build directory. In VS Code,
use:

1. `CMake: Select Configure Preset`
2. Select the preset matching your Mac
3. `CMake: Build`
4. Press `F5`

## Important

If the project is moved or renamed after configuration, delete the selected
build directory and configure again so the generated shader path is refreshed.
